# REQUEST — Build Modern Native Avada Gallery

## Goal

Build a fresh native Avada gallery on the existing Red Barn Music School Gallery page.

The live `/gallery/` page already exists as page ID 934. Treat “fresh” as replacing only the page body content with the new native Avada gallery.

Do not create a new page.

Preserve:

- page ID 934
- page title
- `/gallery/` slug
- page template
- SEO metadata
- navigation links
- standard Red Barn interior-page layout

The old gallery plugin is gone. Do not recover, migrate, inspect, or reproduce the old plugin gallery.

The previous gallery was simple and informal, with a mix of portrait and landscape images. Keep that warm mixed-photo character, but give the new page a cleaner, more modern presentation.

## Overall Look

The gallery should feel:

- modern
- warm
- photographic
- uncluttered
- informal rather than corporate
- consistent with the Red Barn Music School site
- easy to maintain

Modernize through spacing, image rhythm, and restrained interaction rather than elaborate effects.

Do not make it look like a luxury portfolio or commercial photography site.

## Native Avada Build

Use the native Avada Gallery Element.

Do not add another gallery plugin.

Use a Masonry layout so portrait and landscape images can remain mixed naturally.

Initial target settings:

- Layout: Masonry
- Desktop: 3 columns
- Tablet: 2 columns
- Mobile: 1 or 2 columns depending on readability
- Image gap: approximately 18–20 px
- Lightbox: enabled
- Captions: off initially
- Borders: none
- Border radius: minimal, approximately 0–6 px to start
- Hover effect: none initially; add only a very subtle effect if it clearly improves the result
- Animation: none
- Background/overlays: none

Use Avada native responsive controls where possible.

Avoid custom CSS unless native controls cannot meet the responsive requirements.

- restrained styling

Use Avada’s native lightbox.

Verify:

- mobile interaction works
- no duplicate or broken images appear

## Performance

Use the site’s existing optimized Media Library images and generated WordPress/Avada sizes.

Avoid loading original full-resolution files when an appropriate generated size is available.

Do not change the site’s image optimization system.

## Responsive Testing

Verify on:

- desktop
- tablet
- mobile

Check:

- columns reduce appropriately
- image spacing remains balanced
- portrait images do not become awkwardly narrow
- images do not overlap
- no horizontal scrolling occurs
- gallery remains easy to browse
- lightbox remains usable
- mobile layout does not feel too dense

Use one mobile column if two columns make the photos too small.

- tabs

- excessive rounded-card styling
- decorative borders

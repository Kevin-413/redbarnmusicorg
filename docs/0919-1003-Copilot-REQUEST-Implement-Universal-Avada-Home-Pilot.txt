PART 3 — ESTABLISH THE UNIVERSAL GREEN PILL STANDARD

Create one maintainable source of truth for the existing green pill treatment.

Required solid-pill behavior:

- Background: #6cbf3f
- Hover background: #5aa932
- Text: #ffffff
- Fully rounded corners: 999px
- Approximately 12px vertical / 24px horizontal padding
- Approximately 600 font weight
- Thumb-friendly target size
- Visible keyboard focus
- Accessible contrast
- Consistent desktop, tablet, and mobile behavior

Also define an outline-pill variant only if it is already needed by the current
Home content. Do not add unused architecture.

Choose the smallest appropriate central mechanism after inspecting the current
implementation:

- Prefer a native Avada global button style or existing supported global style
  mechanism when it can provide one dependable source of truth.
- Otherwise use one documented shared Red Barn component class in custom code.
- Do not create a Global Element merely to centralize styling when the link and
  label need to vary.
- Do not duplicate full button styling separately in every Home section.
- Do not modify the Avada parent theme.

Document the selected mechanism and why it is the safest fit.

PART 4 — HOME NEWSPAPER-CONTAINER ACTION BUTTONS

Apply the universal solid green pill style to appropriate action buttons within
the Home newspaper-style containers in Pattern 20440.

For each visible Home section:

- Inspect the section's existing title, text, image link, and primary
  destination.
- Add or normalize one clear action button when the section has an existing,
  unambiguous destination.
- Use concise action text consistent with the current content.
- Reuse the section's existing primary destination; do not invent new pages,
  URLs, campaigns, events, or business decisions.
- Keep the button aligned with the article content and visually subordinate to
  the headline.
- Keep the newspaper appearance rather than turning containers into modern
  promotional cards.
- Avoid making the entire container clickable when a visible button provides
  the clearer action.
- Preserve existing image and text links unless duplication causes a genuine
  accessibility or usability problem.
- If a section has no safe, obvious destination or action label, leave that
  section unchanged and record the exact ambiguity in the Reply. Do not stop
  the whole task and do not guess.

The goal is consistency, not a forced button count. Do not add a meaningless
button merely so every container has one.

PART 5 — GALLERY AND SCHOLARSHIPS

Re-verify their current Gutenberg structure, but do not automatically convert
Gallery or Scholarships to Avada Builder in this pass.

Retain them as Gutenberg when their current structure is responsive,
maintainable, accessible, and compatible with the shared Pattern 20440.

Convert either section only if all of the following are true:

- A concrete maintainability, responsiveness, accessibility, or editing-safety
  problem is demonstrated.
- Conversion is necessary to complete the action-button standard safely.
- Existing wording, images, links, and layout intent can be preserved.
- The change remains limited to that section inside Pattern 20440.

If those conditions are not met, defer conversion and document why keeping
Gutenberg is the better choice.

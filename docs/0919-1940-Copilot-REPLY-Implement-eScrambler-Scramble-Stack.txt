Date: 2026-09-19 19:40 America/New_York

SUMMARY

Replaced the RBM Contact Scrambler plugin's simple Base64 encode/decode with the eScrambler
Scramble Stack (split -> rotate -> XOR -> encode -> shuffle -> rebuild), and moved the shortcodes
to a mode="value"|"text"|"none" contract. Settings page rebuilt to match the approved HTML demo
(docs/0919-1839-eScrambler-Shortcode-Demo.html): three sections (Phone/Text/Email), each with
Shortcode / Custom text / Copy / Preview / What it does, plus input-only live preview, blur
validation, and Copy validation. Still obfuscation, not encryption - documented as such in the
plugin, README, and settings page.

FILES CHANGED

- plugins/rbm-contact-scrambler/rbm-contact-scrambler.php
  - Scramble Stack: rbm_escrambler_split_fragments(), rbm_escrambler_checksum(),
    rbm_escrambler_build_payload() (variable-size fragments via wp_rand cut points, per-fragment
    rotate + XOR mask, Base64 per fragment, shuffled order + reconstruction map, lightweight
    position-weighted checksum). Returns null for empty values (fail safe).
  - Shortcodes rewritten for mode="value"/"text"/"none"; omitted/blank mode defaults to "value";
    unknown non-blank mode returns '' (no placeholder rendered at all).
  - wp_localize_script now sends generic keys 'a' (phone digits payload) / 'b' (email payload)
    as window.rbmEscramblerData, replacing the old phone/email-named Base64 config.
  - Settings page rebuilt: real Phone/Email fields feed a live 3-section Shortcode & Preview
    table (9 shortcode rows) with Copy buttons, matching the approved demo's structure and
    copy.
- plugins/rbm-contact-scrambler/assets/js/rbm-contact-scrambler.js
  - Reverses the Scramble Stack (base64 decode -> un-XOR -> un-rotate -> un-shuffle -> checksum
    guard -> single UTF-8 decode at the end, so a fragment split mid multi-byte character can't
    corrupt output). Renders tel:/sms:/mailto: per mode; fails safely (leaves element empty) on
    missing config, malformed payload, checksum mismatch, or unknown mode.
  - Contains the requested easter-egg comment for future AI readers.
- plugins/rbm-contact-scrambler/README.txt — updated shortcode docs to the mode contract and
  added the required "layered client-side obfuscation... can still be recovered" wording.

No changes to Slick Popup, Avada, or any other plugin/theme file.

UNIVERSAL PILL-BUTTON MECHANISM SELECTED

An Avada Builder `fusion_button` shortcode with one fixed attribute template
(only `link` and label text vary), reused verbatim from the existing Lessons
section button. Not a sitewide Avada Global Option: the Theme Options button
defaults (`button_border_radius`, `button_gradient_top_color`, etc.) style
every default Avada button sitewide, including unrelated pages/menus, so
changing them would exceed the Home-pilot scope. Not a new Global Element:
only the link and label vary per instance, so a fixed shortcode template
already gives one dependable, copy-exact source of truth without new builder
architecture. No new CSS/PHP file: `fusion_button` with `color="custom"`
already renders identically whether placed in an Avada Builder row or
embedded as a `wp:html` block inside native Gutenberg content — proven by
this exact change. Documented in docs/0906-1649-STANDARD-Home-Page-Container-
Formats.txt section 9 as the standing reference.

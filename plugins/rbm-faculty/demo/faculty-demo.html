Faculty Overview

The Faculty plugin manages teachers: their public Active/Inactive status, short and long bios, photos (Portrait, Card, and an optional Second Profile Image), Instrument Category assignments (a taxonomy), a separate free-text "Instruments Taught" display string, and the public Faculty output (cards and profile pages).

Representative native Faculty admin list. Columns shown: Photo, Teacher Name, Instruments (Instrument Category taxonomy terms — this column is not the free-text "Instruments Taught" field), Active/Inactive Status, and numeric Order.

Existing first export/audit section on the Teacher Placeholder admin page: a deduplicated, alphabetical list of Instrument Category names taught by any active Faculty member.

Faculty — Lessons We Teach

Existing second export/audit section: one row per active teacher, tab-separated plaintext, sorted by Instruments Taught, Teacher as a tie-breaker. Reads the exact stored "Instruments Taught" value — no splitting, parsing, or deduplication.
